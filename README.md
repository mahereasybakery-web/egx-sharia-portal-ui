# واجهة منظومة الأسهم الشرعية المصرية (مستودع نقي ومستقل 100%) | EGX Sharia Portal UI

مستودع مستقل تماماً ومخصص للواجهة الأمامية والتصميم البصري التفاعلي لتطبيق **منظومة الأسهم الشرعية في البورصة المصرية**.

---

## 💎 ميزات هذا المستودع المنفصل:
1. **صفر أكواد قديمة (Zero Legacy Code)**: لا يحتوي على أي سطر كود من سكريبتات الأتمتة القديمة أو السكرابرز أو قواعد البيانات السابقة.
2. **صفر أرقام أو بيانات محفظة مسبقة (Pure Zero State)**:
   - رصيد المحفظة: `0.00 ج.م`.
   - الأرباح والخسائر: `+0.00 ج.م (+0.00%)`.
   - عدد الأصول: `0 أصل`.
   - المؤشرات وأسعار السوق: علامات نائبة جاهزة للربط `--`.
   - حالة فارغة احترافية (Empty State UI) جاهزة لاستقبال أي مستخدم أو بيانات جديدة من الصفر.
3. **تصميم عصري متجاوب**:
   - دعم الوضع الليلي الفاخر (Dark Mode) والوضع النهاري (Light Mode) وزر الخصوصية (Privacy Mode).
   - مبني بالكامل على Tailwind CSS بنظام Glassmorphism المتناسق ومحاذاة كاملة لليمين (RTL).
4. **شاشات وتفاعلات الواجهة الست**:
   - `محفظتي`: لوحة الأصول والبطاقات والشريط النسبي.
   - `نبض السوق`: شاشة متابعة أسعار الأسهم.
   - `الأخبار`: موجز الأخبار الاقتصادية.
   - `الأبحاث`: بطاقات التقييم ومكررات الأرباح.
   - `التقارير`: قالب التقارير الاستثمارية اليومية القابل للطباعة.
   - `أدواتي`: حاسبة عمولات التداول (0.7%) وحاسبة زكاة الأسهم (2.5%).
   - نافذة **مستشار Gemini AI** التفاعلية.
5. **تطبيق ويب تقدمي (PWA)**: جاهز للتثبيت الفوري كأيقونة تطبيق مستقل على الهواتف الذكية.
