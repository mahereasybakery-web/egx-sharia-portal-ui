# منظومة الأسهم الشرعية المصرية (الإصدار النظيف المحدث v2.0 Pro) | EGX Sharia Portal

منصة متكاملة ومحدثة بالكامل للأسهم والصناديق الاستثمارية المتوافقة مع الشريعة الإسلامية في البورصة المصرية (EGX).
تمت إعادة بناء المنظومة من الصفر بهندسة برمجية نظيفة ومجزأة (Modular Clean Architecture) خالية 100% من الأخطاء والتكرارات، مع التطابق الكامل مع الشكل القديم المعتمد للبرنامج.

---

## 💎 الهيكل البرمجي المعماري المحدث (Modular Architecture):

| الملف | الوظيفة والمسؤولية البرمجية |
| :--- | :--- |
| **`index.html`** | الهيكل البصري الرئيسي والتنقل والتصميم المتجاوب (Tailwind CSS & Glassmorphism). |
| **`css/style.css`** | ملف التنسيقات الموحد (دعم كامل لمحاذاة اليمين RTL، الوضع الليلي الفاخر، الوضع النهاري النقي، وضع الخصوصية 🔒، وتنسيق الطباعة). |
| **`js/data.js`** | مستودع البيانات المعتمدة الموحد (الأسهم الـ 8 المتوافقة، الصناديق الـ 4، الذهب عيار 24، مؤشرات البورصة، وبيانات المزادات). |
| **`js/portfolio.js`** | محرك المحفظة المالية الدقيق وفق معايير المحاسبة SOCPA / IFRS (حساب الرصيد، التكلفة، الأرباح غير المحققة، الأوزان النسبية، والعمولات بدقة 0.00 ج). |
| **`js/performance.js`** | محرك الرسوم البيانية التفاعلية (Chart.js) لمقارنة أداء المحفظة مع مؤشر EGX33 عبر الفترات: (1D, 1W, 1M, 3M, YTD, ALL). |
| **`js/daily-reports.js`** | محرك التقارير الاستثمارية اليومية الشاملة مع مقارنة أثر الجلسة (افتتاح اليوم = إغلاق الأمس). |
| **`js/calculators.js`** | حاسبات الاستثمار (عمولات التداول 0.70%، زكاة الأسهم 2.5%، وصافي عائد أذون الخزانة بعد ضريبة 20%). |
| **`js/gemini-ai.js`** | المستشار المالي والشرعي الذكي المدعوم بنماذج Gemini AI مع دعم الاستشارة الذاتية وحفظ المفتاح محلياً. |
| **`js/app.js`** | المنسق الرئيسي للتطبيق (توقيت مصر الحي، تبديل المظهر، إدارة النوافذ المنبثقة، وتثبيت الـ PWA). |

---

## 🌟 مميزات الإصدار المحدث:
- **صفر تكرارات أو كود فوضوي**: تم التخلص تماماً من كتل الأكواد المتضخمة القديمة.
- **التطابق البصري التام مع الشكل القديم**: الحفاظ على شريط التيكر العلوي، البطاقة الكبرى للرصيد، البطاقات المصغرة الأربع، شريط الأوزان الملون، بطاقات الأسهم التفصيلية، شريط التنقل السفلي الفاخر، والزر العائم للذكاء الاصطناعي.
- **تطبيق ويب تقدمي (PWA)**: جاهز للتثبيت الفوري كأيقونة تطبيق مستقل عبر `manifest.json` و `sw.js`.
